# ♾️ Infinite Captcha

**Infinite Captcha** — це веб-гра, яка перевіряє ваші нерви та швидкість мислення. Розв'язуйте капчі, що постійно ускладнюються, ставте нові рекорди та змагайтеся з іншими гравцями у глобальній таблиці лідерів!

## ✨ Головні фічі
* **Нескінченна генерація рівнів:** Завдання стають дедалі складнішими з кожним кроком.
* **Система рекордів:** Ваш найкращий результат (кількість пройдених рівнів) автоматично зберігається після програшу.
* **🏆 Зал Слави (Leaderboard):** Переглядайте Топ-10 найкращих гравців у реальному часі на окремій сторінці.

## 📁 Структура проекту
Проект побудований за принципами чистої архітектури та розділений на три основні модулі:
*  **`InfiniteCaptcha.Api/`** — Серверна частина (Бекенд). Написана на ASP.NET Core Web API. Відповідає за перевірку відповідей, генерацію завдань та роботу з базою даних (Entity Framework Core + SQLite).
*  **`InfiniteCaptcha.Client/`** — Інтерфейс користувача (Фронтенд). Написаний на Blazor WebAssembly.
*  **`InfiniteCaptcha.Shared/`** — Спільна бібліотека класів. Містить DTO-моделі для безпечного обміну даними між клієнтом та сервером.

## 🚀 Як запустити гру 

Ми налаштували зручний запуск проекту, щоб вам **не доводилося** вручну відкривати кілька терміналів, тому запуск відбувається за посиланням на сайт.

## 🗄️ База даних
Проект використовує локальну базу даних **SQLite**. 
Вам не потрібно встановлювати жодних важких SQL-серверів — при першому запуску бекенду база даних автоматично налаштується і буде готова записувати ваші рекорди.
